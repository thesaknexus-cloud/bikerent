# BikeMate API

Spring Boot API for BikeMate owner/renter rental sessions. Run `mvnw.cmd spring-boot:run` from this folder. Local data uses an H2 file DB; PostgreSQL can be selected with `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, and `DB_DRIVER=org.postgresql.Driver`. See the repository README for the two-account flow, security model, fine calculation, and deployment configuration.
